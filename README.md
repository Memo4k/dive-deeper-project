# Deep Dive Explorer

Create a premium, futuristic educational project website called:

SCUBA DIVER REBREATHER

This is a student innovation project developed around three technical lenses:

1. Web Development

2. Embedded Systems

3. No Technology Required

The website should NOT look like a generic diving website, travel website, or ordinary e-commerce template.

The core creative concept is:

"The deeper you go, the more you discover."

Design the website as an immersive underwater journey. The user should feel like they are gradually descending from the ocean surface into deeper water while discovering the project.

IMPORTANT:

- The official project name must always be "SCUBA DIVER REBREATHER".

- Do not rename the project.

- Do not use "The Underwater Experience" as the project name.

- "Underwater Experience" is only the visual storytelling concept.

- This is a student project/prototype, not a real commercial diving equipment store.

- Do not create real payment functionality.

- Do not provide dangerous step-by-step instructions for operating a real rebreather.

- Keep technical information educational and high-level.
